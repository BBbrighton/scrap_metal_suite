# คู่มือพนักงาน - ระบบ POS รับซื้อเศษโลหะ


## สารบัญ

1. เริ่มต้นใช้งาน
2. หน้าจอชั่งเศษ (Scrap Terminal)
3. หน้าจอชั่งรถ (Truck Terminal)
4. การปิด Session
5. เคล็ดลับการใช้งาน
6. การแก้ไขปัญหาเบื้องต้น


---


## 1. เริ่มต้นใช้งาน


### ขั้นตอนที่ 1: เข้าสู่ระบบ

1. เปิดเว็บไซต์ระบบ
2. ไปที่ /pos
3. ใส่ Email และรหัสผ่าน
4. กด Login


### ขั้นตอนที่ 2: เลือกประเภทหน้าจอ

หลังจาก Login จะเห็นหน้าจอให้เลือก 2 ตัวเลือก:

**ชั่งเศษ (Scrap Weighing)**
สำหรับชั่งเศษโลหะแต่ละประเภท

**ชั่งรถ (Truck Scale)**
สำหรับชั่งน้ำหนักรถเข้า-ออก


### ขั้นตอนที่ 3: เลือกเครื่องชั่ง

หลังจากเลือกหน้าจอ ต้องเลือกเครื่องชั่งที่จะใช้

**วิธีเลือก:**
- คลิกที่การ์ดเครื่องชั่งที่แสดงว่า "ว่าง"
- หรือ สแกน QR Code ที่ติดอยู่ที่เครื่องชั่ง

**หมายเหตุ:**
- เครื่องชั่งที่มีคนใช้อยู่จะแสดงเป็นสีแดง
- ต้องรอจนกว่าเครื่องชั่งจะว่าง หรือใช้เครื่องอื่น

## 2. หน้าจอชั่งเศษ (Scrap Terminal)


### ส่วนประกอบของหน้าจอ

**แถบด้านบน:**
- ชื่อระบบ
- เครื่องชั่งที่ใช้
- ชื่อพนักงาน
- ปุ่มเปลี่ยนธีม
- ปุ่มเปลี่ยนภาษา
- ปุ่มปิดกะ

**ส่วนซ้าย:**
- แท็บหมวดหมู่สินค้า (ทองแดง, อลูมิเนียม, เหล็ก, สแตนเลส)
- ปุ่มสินค้าแต่ละรายการพร้อมราคา

**ส่วนขวา:**
- ช่องค้นหา Order
- ข้อมูล Order ที่เลือก
- ช่องใส่น้ำหนัก
- ตะกร้าสินค้า


### วิธีใช้งานหน้าจอชั่งเศษ


**ขั้นตอนที่ 1: ค้นหา Order**

วิธีที่ 1 - พิมพ์ค้นหา:
1. พิมพ์รหัส Order หรือทะเบียนรถในช่องค้นหา
2. เลือกจากรายการที่แสดง

วิธีที่ 2 - สแกน QR/Barcode:
1. กดปุ่ม [สแกน]
2. ส่องกล้องไปที่ QR Code หรือ Barcode ของ Order
3. ระบบจะดึงข้อมูล Order มาให้อัตโนมัติ


**ขั้นตอนที่ 2: เลือกประเภทเศษ**

1. คลิกที่แท็บหมวดหมู่ (ทองแดง, อลูมิเนียม, ฯลฯ) เพื่อกรอง
2. คลิกที่ปุ่มสินค้าที่ต้องการ
3. สินค้าที่เลือกจะแสดงในส่วน "สินค้าที่เลือก"


**ขั้นตอนที่ 3: ใส่น้ำหนัก**

1. พิมพ์น้ำหนักในช่อง "น้ำหนัก"
2. กดปุ่ม [เพิ่มลงตะกร้า]

เคล็ดลับ:
- ใส่ทศนิยมได้ เช่น 12.5, 100.75
- ถ้าเครื่องชั่งเชื่อมต่อระบบ จะดึงน้ำหนักมาให้อัตโนมัติ


**ขั้นตอนที่ 4: ตรวจสอบตะกร้า**

ตะกร้าจะแสดงรายการทั้งหมดที่ชั่งแล้ว

ตัวอย่าง:
สายทองแดง - 12.5 kg
ท่อทองแดง - 8.0 kg
อลูเศษ - 25.0 kg
รวม: 45.5 kg

การลบรายการ: กดปุ่ม [x] ที่รายการที่ต้องการลบ
การล้างตะกร้า: กดปุ่ม [ล้างตะกร้า] เพื่อลบทุกรายการ


**ขั้นตอนที่ 5: บันทึกน้ำหนัก**

1. ตรวจสอบรายการในตะกร้าให้ถูกต้อง
2. กดปุ่ม [บันทึก]
3. ระบบจะบันทึกข้อมูลและล้างตะกร้า

เมื่อบันทึกสำเร็จจะแสดง:
- Order: ORD-2025-00001
- น้ำหนักรวม: 45.5 kg

## 3. หน้าจอชั่งรถ (Truck Terminal)

หน้าจอนี้ใช้สำหรับบันทึกน้ำหนักรถเข้า-ออก (สะพานชั่ง)


### ส่วนประกอบของหน้าจอ

**แถบด้านบน:**
- ชื่อระบบ
- เครื่องชั่งที่ใช้
- ชื่อพนักงาน
- ปุ่มเปลี่ยนธีม
- ปุ่มเปลี่ยนภาษา
- ปุ่มปิดกะ

**ส่วนค้นหา:**
- ช่องค้นหา Order
- ปุ่มสแกน

**ส่วนข้อมูล Order:**
- รหัส Order
- ชื่อผู้ขาย
- ทะเบียนรถ
- วันที่

**ส่วนบันทึกน้ำหนัก:**
- ช่องน้ำหนักรถเข้า (Gross)
- ช่องน้ำหนักรถออก (Tare)
- ปุ่มบันทึก

**ส่วนสรุป:**
- น้ำหนักสุทธิ (Net)
- น้ำหนักเศษรวม
- ส่วนต่าง (Variance)

**ส่วนเพิ่มเติม:**
- ช่องหมายเหตุ
- ปุ่มถ่ายรูป


### วิธีใช้งานหน้าจอชั่งรถ


**ขั้นตอนที่ 1: ค้นหา Order**

เหมือนกับหน้าจอชั่งเศษ:
- พิมพ์รหัส Order หรือทะเบียนรถ
- หรือสแกน QR/Barcode


**ขั้นตอนที่ 2: บันทึกน้ำหนักรถเข้า (Gross Weight)**

เมื่อรถเข้ามาพร้อมเศษโลหะ:

1. รอให้รถขึ้นสะพานชั่งและหยุดนิ่ง
2. อ่านน้ำหนักจากเครื่องชั่ง
3. ใส่ตัวเลขในช่อง "น้ำหนักรถเข้า"
4. กดปุ่ม [บันทึกน้ำหนักเข้า]

ระบบจะบันทึกพร้อมเวลา:
- น้ำหนัก: 15,000 kg
- เวลา: 09:30:15


**ขั้นตอนที่ 3: บันทึกน้ำหนักรถออก (Tare Weight)**

เมื่อรถขนเศษลงแล้วและกำลังจะออก:

1. รอให้รถขึ้นสะพานชั่งและหยุดนิ่ง
2. อ่านน้ำหนักจากเครื่องชั่ง
3. ใส่ตัวเลขในช่อง "น้ำหนักรถออก"
4. กดปุ่ม [บันทึกน้ำหนักออก]


**ขั้นตอนที่ 4: ตรวจสอบส่วนต่าง**

หลังจากบันทึกทั้ง 2 ค่า ระบบจะคำนวณให้:

ตัวอย่างสรุปน้ำหนัก:
น้ำหนักรถเข้า (Gross): 15,000 kg
น้ำหนักรถออก (Tare): 5,000 kg
น้ำหนักสุทธิ (Net): 10,000 kg
น้ำหนักเศษจากการชั่ง: 9,850 kg
ส่วนต่าง: 150 kg (1.5%)
สถานะ: ผ่าน (ไม่เกิน 2%)


**ความหมายของสถานะ:**

ผ่าน (สีเขียว) - ส่วนต่างไม่เกิน 2% - ปล่อยรถออกได้
ไม่ผ่าน (สีแดง) - ส่วนต่างเกิน 2% - อาจต้องชั่งใหม่ หรือแจ้งหัวหน้า


**ขั้นตอนที่ 5: เพิ่มหมายเหตุ/ถ่ายรูป (ถ้าต้องการ)**

หมายเหตุ:
- ใส่ข้อความเพิ่มเติม เช่น "เศษเปียกน้ำฝน"

ถ่ายรูป:
1. กดปุ่ม [ถ่ายรูปรถ]
2. ถ่ายรูปป้ายทะเบียนหรือรถ
3. รูปจะถูกบันทึกพร้อม Order

## 4. การปิด Session


### เมื่อจบกะหรือเลิกงาน

1. กดปุ่ม [ปิดกะ] ที่มุมขวาบน
2. ระบบจะถามยืนยัน "ยืนยันการปิดกะ?"
3. กด [ปิดกะ] เพื่อยืนยัน
4. ระบบจะแสดงสรุปการทำงาน

ตัวอย่างสรุปกะการทำงาน:
Session: SES-2025-00001
เวลาเปิด: 08:00:15
เวลาปิด: 17:30:45
จำนวนรายการชั่ง: 25 รายการ
น้ำหนักรวม: 2,450.5 kg

## 5. เคล็ดลับการใช้งาน


### 5.1 เปลี่ยนภาษา

กดปุ่ม TH หรือ EN ที่แถบด้านบน
- TH = ภาษาไทย
- EN = ภาษาอังกฤษ


### 5.2 เปลี่ยนธีม (สว่าง/มืด)

กดปุ่มรูปพระจันทร์หรือพระอาทิตย์ที่แถบด้านบน
- รูปพระจันทร์ = โหมดมืด
- รูปพระอาทิตย์ = โหมดสว่าง


### 5.3 ดูสรุประหว่างกะ

กดปุ่ม [สรุป] เพื่อดูสถิติปัจจุบัน:
- เปิดมาแล้วกี่ชั่วโมง
- จำนวนรายการ
- น้ำหนักรวม


### 5.4 ใช้แป้นพิมพ์ลัด

Enter = ยืนยัน/เพิ่มลงตะกร้า
Esc = ยกเลิก/ปิดหน้าต่าง
Tab = เลื่อนไปช่องถัดไป


### 5.5 การค้นหา Order อย่างรวดเร็ว

รู้รหัส Order: พิมพ์ ORD-2025-00001
รู้ทะเบียนรถ: พิมพ์ กข-1234
รู้บางส่วน: พิมพ์ 1234 ก็หาเจอ

## 6. การแก้ไขปัญหาเบื้องต้น


### ปัญหา: ไม่สามารถเข้าหน้า POS ได้

อาการ: หน้าจอแสดง "Access Denied" หรือ "ไม่มีสิทธิ์"

วิธีแก้:
1. ตรวจสอบว่า Login ถูกต้อง
2. ติดต่อหัวหน้างานเพื่อขอสิทธิ์ "POS Operator"


### ปัญหา: เปิด Session ไม่ได้

อาการ: ระบบแจ้ง "คุณมี Session ที่เปิดอยู่แล้ว"

วิธีแก้:
1. หา Session เก่าที่ค้างอยู่
2. ปิด Session เก่าก่อน
3. หรือติดต่อหัวหน้างานให้ช่วยปิด


### ปัญหา: เลือกเครื่องชั่งไม่ได้

อาการ: เครื่องชั่งแสดงว่า "ใช้งานอยู่"

วิธีแก้:
1. รอให้คนที่ใช้อยู่ปิด Session
2. หรือใช้เครื่องชั่งตัวอื่นที่ว่าง
3. หรือติดต่อหัวหน้างานให้ช่วยปลดล็อค


### ปัญหา: ค้นหา Order ไม่เจอ

อาการ: พิมพ์ค้นหาแล้วไม่มีผลลัพธ์

สาเหตุที่เป็นไปได้:
- Order อาจเป็นของวันก่อนหน้ามากกว่า 2 วัน
- พิมพ์รหัสผิด

วิธีแก้:
1. ตรวจสอบว่าพิมพ์ถูกต้อง
2. ลองพิมพ์รหัส Order เต็ม เช่น ORD-2025-00001
3. ติดต่อหัวหน้างานเพื่อตรวจสอบในระบบ


### ปัญหา: บันทึกน้ำหนักไม่ได้

อาการ: กดปุ่มบันทึกแล้วไม่มีอะไรเกิดขึ้น หรือแสดงข้อผิดพลาด

วิธีแก้:
1. ตรวจสอบว่าเลือก Order แล้ว
2. ตรวจสอบว่าใส่น้ำหนักแล้ว
3. ตรวจสอบว่ามีสินค้าในตะกร้า (สำหรับหน้าจอชั่งเศษ)
4. ลอง Refresh หน้าจอแล้วทำใหม่


### ปัญหา: ส่วนต่างน้ำหนักเกินเกณฑ์

อาการ: แสดงสถานะ "ไม่ผ่าน" (สีแดง)

สิ่งที่ต้องทำ:
1. ตรวจสอบว่าชั่งรถถูกคัน (ทะเบียนตรงกัน)
2. ตรวจสอบว่าชั่งเศษครบทุกรายการ
3. แจ้งหัวหน้างานเพื่อตัดสินใจ:
   - ชั่งรถใหม่
   - ชั่งเศษใหม่
   - หรืออนุมัติให้ผ่าน
