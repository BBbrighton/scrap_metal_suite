# Truck Terminal — Operator Guide / คู่มือผู้ใช้งาน

> **Status:** Production
> **Who / ใคร:** POS Operator (ต้องมีบทบาท `POS Operator`)
> **Where / ที่ไหน:** `/pos/truck?session=<รหัสกะ>` — เข้าจากหน้า `/pos` แล้วกดการ์ด **Truck Scale**
> **Last verified:** 2026-08-25 — ทดสอบกับระบบจริง / tested against a live site

---

## ⚡ ฉบับย่อ — ชั่งรถคันหนึ่งทำแค่นี้ / The short version

รถ 1 คัน = ชั่ง 2 ครั้ง คือ **ตอนเข้า** กับ **ตอนออก**
One truck, two weighings: **in** with the load, **out** empty.

| | ตอนรถเข้า / Truck arrives | ตอนรถออก / Truck leaves |
|---|---|---|
| **1** | เปิด `/pos` → การ์ด **Truck Scale** → เลือกตาชั่ง | เลือกใบส่งของใบเดิม |
| **2** | ค้นหาใบส่งของ `DO-…` หรือทะเบียนรถ | กดแท็บ **น้ำหนักเปล่า / Tare** |
| **3** | แท็บ **น้ำหนักรวม / Gross** (เลือกไว้ให้แล้ว) | รถขึ้นตาชั่งเปล่า รอ `STABLE` |
| **4** | รถขึ้นตาชั่ง รอป้าย `STABLE` | กด **บันทึกน้ำหนัก** → **ยืนยัน** |
| **5** | กด **บันทึกน้ำหนัก** → **ยืนยัน** | น้ำหนักสุทธิคำนวณให้เอง + สลิปพิมพ์ออก |
| **6** | ฉีกสลิปให้คนขับ **บอกให้เก็บไว้** | กด **✔ เสร็จสิ้นใบส่งของ** |

**3 อย่างที่ต้องจำ / Three things to remember**

1. **น้ำหนักสุทธิ = น้ำหนักรวม − น้ำหนักเปล่า** ระบบคิดให้เอง คุณไม่ต้องคำนวณ
   Net = Gross − Tare. The system does the arithmetic.
2. **กะปิดเองถ้าไม่มีการบันทึก 90 นาที** — ระหว่างรถเข้ากับรถออกมักเกิน ถ้าโดนปิด ให้เปิดกะใหม่ **น้ำหนักที่ชั่งไว้ยังอยู่ครบ ไม่ต้องชั่งซ้ำ**
   Sessions auto-close after 90 minutes with no save, which the gap between weigh-in and weigh-out often exceeds. Just open a new one — **the gross weight you already saved is safe**.
3. **ชั่งผิด ให้ชั่งซ้ำในแท็บเดิม** พร้อมใส่เหตุผล — ไม่ต้องออกใบใหม่ เลข `TW-…` เดิมยังใช้ได้
   Got it wrong? Reweigh on the same tab with a reason. No new document — the same `TW-…` number stands.

> ⚠️ **ข้อความบางจุดยังขึ้นเป็นรหัสภาษาอังกฤษ** เช่น `confirmReweight`, `missingGrossWeight` — เป็นข้อบกพร่องที่ทราบแล้ว **ไม่กระทบข้อมูล** ความหมายอยู่ในตารางข้อ 8
> Some messages still show raw codes instead of Thai. Confirmed still present on 25 Aug 2026. **Harmless** — the translations are in §8.

## 1. What this is for / งานนี้คืออะไร

หน้าจอนี้คือ **ตาชั่งรถ (weighbridge)** ทำหน้าที่เดียวคือชั่งรถ 2 ครั้ง — ตอนรถเข้าพร้อมของ (**น้ำหนักรวม / Gross**) และตอนรถออกหลังลงของหมดแล้ว (**น้ำหนักเปล่า / Tare**) ระบบเอาสองค่านี้ลบกันได้ **น้ำหนักสุทธิ (Net)** คือน้ำหนักของที่ลานรับเข้าจริงตามตาชั่งรถ

This screen is the weighbridge. It does one job: weigh the truck twice — in with the load (**gross**), out empty (**tare**) — and take the difference (**net**). Every weighing prints an 80 mm slip for the driver.

ทุกครั้งที่บันทึกน้ำหนัก ระบบจะสร้างเอกสาร **ใบชั่งรถ (Truck Weight)** เลขที่ขึ้นต้นด้วย `TW-` และ **พิมพ์สลิปให้อัตโนมัติ**

**เมื่อไหร่ที่ใช้ / When you use it**
รถของผู้ขายมาถึงลานและขึ้นตาชั่งรถ — และอีกครั้งตอนรถลงของเสร็จแล้วกำลังจะออก

**ผลลัพธ์ / What you end up with**
ใบชั่งรถ 2 ใบ (`TW-…` ขาเข้า + ขาออก) น้ำหนักสุทธิบนใบส่งของ (`DO-…`) และการเปรียบเทียบว่า **น้ำหนักตาชั่งรถ** ตรงกับ **ผลรวมน้ำหนักถุงที่ชั่งทีละใบ** หรือไม่

> **หน้าจอนี้ไม่ได้ทำอะไร / What this screen does NOT do**
> ไม่ชั่งถุงทีละใบ (ใช้ [12 — Drop-off & Containers](12-dropoff-receiving.md) ที่ `/pos/terminal`)
> ไม่สร้างใบส่งของ (`Dropoff`) — ออฟฟิศสร้างไว้ล่วงหน้าจากหน้า Desk
> ไม่คัดแยกเกรด (ใช้ [20 — Production Sorting](20-production-sorting.md))

## 2. Before you start / เตรียมก่อนเริ่ม

| ต้องมี / You need | หมายเหตุ / Notes |
|---|---|
| **บทบาท `POS Operator`** | ถ้ามีแค่ `POS Manager` หน้าจอจะเปิดได้ แต่ทุกปุ่มจะขึ้น "Access denied. POS Operator role required." → ขอให้แอดมินเพิ่มบทบาท `POS Operator` ให้ |
| **กะ (Session) ที่เปิดอยู่ และยังไม่ผูกตาชั่ง** | 1 คนเปิดได้ 1 กะเท่านั้น ถ้ากะปัจจุบันผูกตาชั่งชั่งของ (Scrap) ไว้แล้ว เปิด `/pos/truck` จะเด้งกลับไป `/pos/terminal` ทันที ต้อง **ปิดกะเดิมแล้วเปิดใหม่** |
| **ตาชั่งรถที่ `usage_type = Truck`** | หน้านี้แสดงเฉพาะตาชั่งประเภท Truck เท่านั้น (เช่น `TRUCK-001`, `TRUCK-002`) ถ้ารายการว่าง → แจ้งแอดมิน |
| **ใบส่งของ (`DO-…`) ที่ออฟฟิศสร้างไว้แล้ว** | ต้องมีเลขทะเบียนรถ (License Plate) และผูกกับใบสั่งซื้ออย่างน้อย 1 ใบ ถ้าไม่มีใบสั่งซื้อผูกอยู่ ระบบจะบันทึกน้ำหนักไม่ได้เลย |
| **เบราว์เซอร์ Chrome หรือ Edge** | การต่อสายตาชั่ง (WebSerial) ใช้ได้เฉพาะ Chrome/Edge — Firefox/Safari ต้องพิมพ์น้ำหนักเอง |
| **สาย USB/Serial เสียบตาชั่งรถ** | ถ้าตาชั่งยังไม่ได้ตั้งค่าพอร์ต (baud rate ฯลฯ) ให้ใช้โหมด **พิมพ์เอง / Manual Entry** ไปก่อน แล้วให้แอดมินตั้งค่าที่ `/scale-test` |
| **เครื่องพิมพ์สลิปความร้อน 80 มม.** | ระบบสั่งพิมพ์อัตโนมัติทุกครั้งที่บันทึกน้ำหนัก |

## 4. Walkthrough: weigh in (gross) / ชั่งเข้า

**สถานการณ์ / Scenario:** รถทะเบียน `70-1234 ปทุมธานี` ของ บจก. สมชายรีไซเคิล มาถึงลาน ออฟฟิศออกใบส่งของ `DO-260821-00003` ไว้แล้ว รถขึ้นตาชั่งพร้อมของเต็มคัน

1. **เปิดกะ** — ไปที่ `/pos` แล้วกดการ์ด **🚚 Truck Scale**
   → เปิดกะใหม่และพาไปที่ `/pos/truck?session=SES-260821-00001`

2. **เลือกตาชั่ง** — หน้าต่าง **เลือกเครื่องชั่ง / Select Scale** จะเด้งขึ้นเอง เลือก `TRUCK-001 - Main Gate` จากรายการ หรือกด **📷 สแกน QR เครื่องชั่ง** แล้วส่องกล้องที่สติกเกอร์บนตู้ตาชั่ง
   → กรอบ **ข้อมูลเครื่องชั่ง** แสดงชื่อ ประเภท (`Weighbridge`) และตำแหน่ง
   → หน้าต่างนี้ **ปิดด้วยการคลิกข้างนอกไม่ได้** ต้องเลือกให้เสร็จ

3. **ต่อสายตาชั่ง** — กด **ยืนยันเครื่องชั่ง / Confirm Scale**
   → Chrome เปิดหน้าต่างเลือกพอร์ต ให้เลือกพอร์ต USB/Serial ของตาชั่งรถ แล้วกด Connect
   → หน้าต่าง **Scale Connection** แสดง `Protocol: HP-05-VAR` และน้ำหนักที่อ่านได้ → กด **ยืนยัน**
   → ป้ายบนหัวจอเปลี่ยนเป็น `⚖ TRUCK-001 ●` จุดเขียว และตัวเลขสดโผล่บนทั้งสองแท็บ

   > **ต่อไม่ติด?** กด **ใช้โหมดพิมพ์เอง / Use Manual Entry** ได้เลย ทำงานต่อได้ปกติ แค่ต้องพิมพ์ตัวเลขเอง

4. **ค้นหาใบส่งของ** — พิมพ์ `DO-260821-00003` หรือ `70-1234` (ค้นด้วยทะเบียนก็ได้) ในช่อง **รหัสใบส่งของ** ทางขวา หรือกด **📷 สแกน** แล้วส่องกล้องที่ QR บนใบส่งของ
   → รายการที่ตรงจะขึ้นมา (ค้นหาแบบบางส่วนจะหาเฉพาะใบส่งของในช่วง ±3 วันจากวันนี้เท่านั้น)

5. **เลือกใบส่งของ** — คลิกที่แถว `DO-260821-00003`
   → ช่องค้นหาหายไป แทนที่ด้วยการ์ดข้อมูล: ผู้ขาย, วันที่, ทะเบียน `70-1234 ปทุมธานี`, สถานะ
   → ฝั่งซ้ายเปลี่ยนจากข้อความ "เลือกใบส่งของเพื่อบันทึกน้ำหนักรถ" เป็นแท็บ **Gross / Tare**
   → ถ้าใบส่งของมีรายการที่ผู้ขายแจ้งไว้ จะมีส่วน **รายการที่คาดหวัง** พับอยู่ กดเพื่อกาง (เช่น `ทองแดงปอก` 3,000.00 Kg, `ทองแดงเล็ก` 2,000.00 Kg)

6. **ให้รถขึ้นตาชั่งและรอค่านิ่ง** — แท็บ **Gross** ถูกเลือกอยู่แล้วโดยค่าเริ่มต้น
   → ตัวเลขสดขยับ พอค่านิ่งจะมีป้าย `STABLE` สีเขียวขึ้น และตัวเลข **เติมลงช่องพิมพ์ให้เอง** เช่น `12480.00`

7. **กด บันทึกน้ำหนัก / Save Weight**
   → หน้าต่างยืนยันขึ้นมา แสดง `น้ำหนักรวม` และ `12480.00 Kg` ตัวใหญ่
   → มีช่อง **หมายเหตุ (ไม่บังคับ)** ถ้าอยากบันทึกอะไรไว้ เช่น "ฝนตก ของเปียก"

8. **กด บันทึกน้ำหนัก ในหน้าต่างยืนยัน**
   → แถบเขียว `✔ 12480.00 Kg` + เวลา + ป้าย `⚖ ตราชั่ง` โผล่ขึ้นใต้ปุ่ม (หายไปเองใน 5 วินาที)
   → แท็บ **Gross** ขึ้นเครื่องหมาย ✔ สีเขียว
   → ช่องพิมพ์ถูกล้าง
   → ปุ่ม **📷 รูปถ่าย** ของแท็บนี้กดได้แล้ว
   → กรอบสรุปสีเขียวโผล่ขึ้น: `Gross 12,480.00 Kg` / `Tare --` / `Net --`
   → **เครื่องพิมพ์สลิปทำงานเอง** — ฉีกสลิปให้คนขับ

**เสร็จแล้วได้อะไร / Result:**
ใบชั่งรถ `TW-260821-00001` (ขาเข้า) สถานะใบส่งของเปลี่ยนเป็น **In Progress** สลิปในมือคนขับมีเลข `TW-…` ตัวเลข 12480.00 ตัวใหญ่ ช่อง `[X] ขาเข้า Gross` ติ๊ก และ QR สองอัน

> **บอกคนขับให้เก็บสลิปไว้** — ตอนขาออกต้องเทียบเลขทะเบียนกัน

## 5. Walkthrough: weigh out (tare) + net / ชั่งออก

**สถานการณ์ / Scenario:** รถคันเดิมลงของหมดแล้ว กำลังจะออกจากลาน ฝั่งชั่งถุงชั่งเสร็จแล้วได้ยอดรวม 4,976.00 กก.

1. **เช็คว่ากะยังเปิดอยู่** — ถ้าหน้าจอขึ้น "This session has been closed" แปลว่ากะถูกปิดอัตโนมัติเพราะไม่มีการใช้งานเกิน 90 นาที → กลับไป `/pos` เปิดกะใหม่ ผูกตาชั่งใหม่ แล้วค้นใบส่งของเดิม (น้ำหนัก Gross ที่บันทึกไว้ยังอยู่ครบ)

2. **เลือกใบส่งของเดิม** — พิมพ์ `DO-260821-00003` แล้วเลือก
   → แท็บ **Gross** มี ✔ อยู่แล้ว กรอบสรุปแสดง `Gross 12,480.00 Kg`

3. **กดแท็บ น้ำหนักเปล่า / Tare**
   → แท็บเปลี่ยนเป็นสีม่วง ข้อความใต้แท็บเปลี่ยนเป็น "ชั่งรถเปล่าหลังขนถ่าย"
   → เคอร์เซอร์ไปที่ช่องพิมพ์ให้เอง

4. **ให้รถขึ้นตาชั่งเปล่า รอ `STABLE`**
   → ช่องพิมพ์เติมให้เอง เช่น `7500.00`

5. **กด บันทึกน้ำหนัก → ยืนยัน**
   → แถบเขียว `✔ 7500.00 Kg` โผล่ แท็บ **Tare** ขึ้น ✔
   → **กรอบสรุปคำนวณ Net ให้ทันที:**

   | | |
   |---|---|
   | น้ำหนักรวม Gross | 12,480.00 Kg |
   | น้ำหนักเปล่า Tare | 7,500.00 Kg |
   | **น้ำหนักสุทธิ Net** | **4,980.00 Kg** |

   → **สลิปขาออกพิมพ์ออกมาเอง** (`[X] ขาออก Tare`)
   → ปุ่ม **✔ เสร็จสิ้นใบส่งของ** โผล่ขึ้นมา

6. **ดูแผงตรวจสอบน้ำหนักทางขวา** — จะโผล่ก็ต่อเมื่อมีทั้ง Net และยอดรวมถุง

   ```
   ค่าต่างรถ (สุทธิ vs เศษวัสดุ)
     น้ำหนักสุทธิรถ      4,980.00 Kg
     น้ำหนักเศษวัสดุรวม  4,976.00 Kg
     ค่าต่างรถ           4.00 Kg (0.08%)
     ✔ ค่าต่างอยู่ในเกณฑ์
   ```

   **อ่านค่ายังไง / How to read it:**
   - **ค่าบวก** = ตาชั่งรถได้มากกว่าผลรวมถุง — ปกติ (ความชื้น ฝุ่น เศษตกค้างในกระบะ)
   - **ค่าลบ** = ผลรวมถุงมากกว่าที่รถหายไป — **ผิดปกติ ให้ตรวจสอบ**
   - **สีเขียว ✔** = อยู่ในเกณฑ์ (ค่าเริ่มต้น 0.1%)
   - **สีเหลือง ⚠** = เกินเกณฑ์ไม่เกิน 2 เท่า
   - **สีแดง ✘** = เกินเกณฑ์เกิน 2 เท่า

   ถ้าใบส่งของมีรายการที่ผู้ขายแจ้งไว้ จะมีอีกกรอบ **ค่าต่างแจ้ง (ผู้ขาย vs จริง)** เทียบน้ำหนักที่แจ้งกับที่ชั่งได้จริง

7. **กด ✔ เสร็จสิ้นใบส่งของ** (ถ้าฝั่งชั่งถุงเสร็จแล้ว)
   → หน้าต่างสรุปขึ้นมา: รหัสใบส่งของ, น้ำหนักสุทธิรถ, น้ำหนักเศษรวม, ค่าต่างทั้งสองแบบ
   → ถ้ายังขาดอะไร จะมีกรอบเตือนสีเหลืองบอกรายการที่ขาด และปุ่ม **Complete** จะกดไม่ได้
   ⚠️ ข้อความในกรอบเตือนตอนนี้ขึ้นเป็นรหัสภาษาอังกฤษ (`missingGrossWeight`, `missingTareWeight`, `noScrapWeights`) — เป็นข้อบกพร่องที่ทราบแล้ว ความหมายคือ *ขาดน้ำหนักขาเข้า / ขาดน้ำหนักขาออก / ยังไม่มีน้ำหนักเศษวัสดุ*

8. **กด Complete**
   → สถานะบนการ์ดเปลี่ยนเป็น **Completed**
   → ปุ่มเสร็จสิ้นหายไป และหน้าจอกลับไปช่องค้นหาใน 2 วินาที พร้อมรับรถคันถัดไป

**เสร็จแล้วได้อะไร / Result:**
ใบชั่งรถ 2 ใบ น้ำหนักสุทธิ 4,980.00 กก. บนใบส่งของ และสถานะตรวจสอบเป็น `Verified` (ถ้าค่าต่างทุกตัวอยู่ในเกณฑ์) หรือ `Needs Review` (ถ้ามีตัวใดเกิน) — กรณี `Needs Review` หัวหน้าจะเป็นคนอนุมัติจากหน้า Desk

> **ไม่ต้องรอฝั่งชั่งถุง** — ฝั่งไหนเสร็จก่อนกด **เสร็จสิ้นใบส่งของ** ได้เลย ถ้าอีกฝั่งยังไม่เสร็จ สถานะตรวจสอบจะเป็น `Pending` ไว้ก่อน

## 6. Walkthrough: reweigh / ชั่งซ้ำ

**สถานการณ์ / Scenario:** บันทึก Gross ไป 12,480.00 แล้ว แต่พบว่ามีคนยืนอยู่บนตาชั่งตอนชั่ง ต้องชั่งใหม่

**หลักการ / The rule:** ใบชั่งรถของแต่ละด้าน (ขาเข้า/ขาออก) มี **ใบเดียวตลอด** ชั่งซ้ำคือ **แก้ตัวเลขในใบเดิม** ไม่ใช่ออกใบใหม่ เลข `TW-…` บนสลิปเดิมยังใช้ได้ — พิมพ์สลิปใหม่ทับได้เลย

1. **เลือกใบส่งของเดิม** และไปที่แท็บที่ต้องแก้ (Gross)

2. **ให้รถขึ้นตาชั่งใหม่ แล้วใส่ค่าใหม่** เช่น `12405.00`

3. **กด บันทึกน้ำหนัก**
   → หน้าต่างยืนยันเปลี่ยนหน้าตา:
   - มีแถบเตือนสีเหลือง ⚠ "This will update the existing weight record"
   - โผล่ช่อง **เหตุผลในการชั่งซ้ำ / Reweight Reason** พร้อมดอกจันแดง `*`
   ⚠️ หัวข้อหน้าต่างจะขึ้นเป็น `confirmReweight` แทนคำว่า "ยืนยันการชั่งซ้ำ" — เป็นข้อบกพร่องที่ทราบแล้ว ไม่กระทบการใช้งาน

4. **กรอกเหตุผล — บังคับ** เช่น `มีคนยืนบนตาชั่งตอนชั่งครั้งแรก`
   → ถ้าปล่อยว่างแล้วกดบันทึก จะขึ้นข้อความเตือนและบันทึกไม่ผ่าน (ระบบตรวจทั้งฝั่งหน้าจอและฝั่งเซิร์ฟเวอร์)

5. **กด บันทึกน้ำหนัก**
   → ตัวเลขในกรอบสรุปเปลี่ยนเป็น 12,405.00 และ Net คำนวณใหม่ทันที
   → **สลิปใหม่พิมพ์ออกมา มีป้าย `** ชั่งซ้ำ **` และเหตุผลที่กรอกไว้พิมพ์อยู่ใต้ป้าย** และหัวสลิปเปลี่ยนเป็น `ใบชั่งรถ (ชั่งซ้ำ)`
   → ใบส่งของถูกทำเครื่องหมายว่ามีการชั่งซ้ำ

> **ค่าเดิมหายไหม?** ไม่หาย ระบบเก็บประวัติการแก้ไขไว้ทั้งหมด หัวหน้าดูย้อนหลังได้จากหน้า Desk ที่ใบชั่งรถใบนั้น

## 7. Walkthrough: photos & remarks / รูปถ่ายและหมายเหตุ

### 7.1 รูปถ่าย / Photos

รูปถ่ายผูกกับ **ใบชั่งรถของแต่ละด้าน** แยกกัน — รูปของ Gross กับรูปของ Tare อยู่คนละที่

1. **บันทึกน้ำหนักของแท็บนั้นให้เสร็จก่อน**
   → ถ้ายังไม่บันทึก ปุ่ม 📷 จะเป็นสีเทากดไม่ได้ (ทูลทิปขึ้นว่า "Save weight first") ถ้าฝืนกดจะขึ้นข้อความ "Please save the gross weight before taking a photo"

2. **กด 📷 รูปถ่าย** ในแท็บที่ต้องการ
   → เบราว์เซอร์ขอสิทธิ์ใช้กล้อง (ครั้งแรก) → กดอนุญาต
   → กล้องหลังเปิดขึ้น หัวหน้าต่างขึ้นว่า `Gross Weight - ถ่ายรูป`

3. **ปรับซูม/ก้ม-เงย** (ถ้ามี) — แถบเลื่อน **Zoom** ใต้ภาพ มีป้ายบอกว่าเป็น `optical` (ซูมจริงของกล้อง) หรือ `digital` (ครอปกลางภาพ) แถบ **Tilt** จะโผล่เฉพาะกล้องที่รองรับ

4. **กด ถ่ายรูป / Capture**
   → ภาพนิ่งแทนที่ภาพสด ปุ่มเปลี่ยนเป็น **ถ่ายใหม่ / Retake**

5. **เลือกทางใดทางหนึ่ง:**
   - **Add & Take Another** — เก็บรูปนี้แล้วถ่ายต่อ (ถ่ายได้หลายรูป: หน้าจอตาชั่ง + ป้ายทะเบียน + สภาพของบนรถ) เห็นจำนวนรูปที่ป้ายมุมบนหน้าต่าง
   - **บันทึกรูป / Save Photo** — เก็บรูปสุดท้ายแล้วอัปโหลดทั้งหมด

6. **หลังอัปโหลดเสร็จ**
   → ข้อความเขียวขึ้น เช่น `2 รูปพร้อมแนบ (3 total)`
   → ปุ่ม 📷 ของแท็บนั้นเปลี่ยนเป็น `📷 รูปถ่าย (3) ✔`
   → จำนวนรูปจะพิมพ์อยู่บนสลิปครั้งถัดไปในช่อง `รูปภาพ:`

> **ปิดหน้าต่างกล้อง** ด้วยปุ่ม ✕ หรือคลิกนอกหน้าต่าง — กล้องจะถูกปิดให้อัตโนมัติ **รูปที่ยังไม่กด Save จะหายไป**

### 7.2 หมายเหตุ / Remarks

หมายเหตุมี **2 ระดับ อย่าสับสน:**

| ระดับ / Level | ใส่ที่ไหน / Where | ไปโผล่ที่ไหน / Where it shows |
|---|---|---|
| **ต่อการชั่ง 1 ครั้ง** | ช่อง **หมายเหตุ** ในหน้าต่างยืนยันตอนกดบันทึกน้ำหนัก | พิมพ์บนสลิปใบชั่งรถใบนั้น |
| **ต่อใบส่งของทั้งใบ** | ปุ่ม **💬 หมายเหตุ** ด้านล่างซ้าย | เก็บบนใบส่งของ (ช่อง Truck Remarks) พิมพ์บนใบส่งของ ไม่โผล่บนสลิป |

**วิธีใส่หมายเหตุระดับใบส่งของ:**

1. เลือกใบส่งของก่อน (ถ้าไม่เลือก กดปุ่มจะไม่มีอะไรเกิดขึ้น)
2. กด **💬 หมายเหตุ**
   → หน้าต่างเปิดขึ้นพร้อมข้อความเดิม (ถ้ามี)
3. พิมพ์ เช่น `คนขับแจ้งว่าของเปียกฝนระหว่างทาง`
4. กด **บันทึกหมายเหตุ / Save Remarks**
   → ข้อความเขียว "บันทึกหมายเหตุแล้ว" และปุ่มเปลี่ยนเป็น `💬 หมายเหตุ ✔`

## 8. What can go wrong / ปัญหาที่พบบ่อย

| อาการ / Symptom | สาเหตุ / Cause | แก้ยังไง / Fix |
|---|---|---|
| เปิด `/pos/truck` แล้วเด้งกลับไป `/pos/terminal` ทุกครั้ง | กะนี้ผูกตาชั่งชั่งของ (Scrap) ไว้แล้ว 1 กะเปลี่ยนตาชั่งไม่ได้ | **ปิดกะ** แล้วเปิดกะใหม่จาก `/pos` โดยกดการ์ด **Truck Scale** |
| ขึ้น "This session has been closed" กลางวัน | กะถูกปิดอัตโนมัติเพราะไม่มีการบันทึกน้ำหนักเกิน **90 นาที** (ระหว่างชั่งเข้ากับชั่งออกมักเกิน) | เปิดกะใหม่ ผูกตาชั่ง ค้นใบส่งของเดิม — **น้ำหนัก Gross ที่บันทึกไว้ยังอยู่ ไม่ต้องชั่งซ้ำ** |
| ขึ้น "This session belongs to another operator" | เปิดลิงก์กะของคนอื่น | กลับไป `/pos` แล้วเปิดกะของตัวเอง |
| ทุกปุ่มขึ้น "Access denied. POS Operator role required." | มีแค่บทบาท `POS Manager` ซึ่งเปิดหน้าได้แต่เรียก API ไม่ได้ | ให้แอดมินเพิ่มบทบาท **`POS Operator`** ให้ผู้ใช้คนนี้ |
| หน้าต่างเลือกตาชั่งขึ้นว่า "No truck scales available" | ไม่มีตาชั่งที่ `usage_type = Truck` หรือถูกปิดใช้งานหมด | แจ้งแอดมินให้สร้าง/เปิดใช้งานตาชั่งประเภท Truck |
| ตาชั่งในรายการเป็นสีเทากดไม่ได้ | ถูกกะอื่นจองอยู่ (`in use`) หรือถูกปิดใช้งาน (`not active`) | รอกะนั้นปิด หรือให้แอดมินปลดล็อก |
| กด **ยืนยันเครื่องชั่ง** แล้วขึ้นหน้าจอ **ต่อไม่สำเร็จ** ทันทีโดยไม่ถามพอร์ต | ตาชั่งตัวนี้ยังไม่ได้ตั้งค่าพอร์ต (baud rate / data bits / parity / stop bits ว่าง) | กด **ใช้โหมดพิมพ์เอง** ทำงานต่อไปก่อน แล้วให้แอดมินตั้งค่าที่ `/scale-test` |
| ขึ้น "WebSerial not supported" | ใช้ Firefox หรือ Safari | เปิดด้วย **Chrome หรือ Edge** — หรือใช้โหมดพิมพ์เอง |
| ตัวเลขสดไม่ขึ้นเลย แม้ต่อสายแล้ว | ตาชั่งไม่ได้เปิด สายหลุด หรือโปรโตคอลอ่านไม่ออก | กดป้ายตาชั่งบนหัวจอ → **เชื่อมต่อใหม่** ถ้ายังไม่ได้ → **ตั้งค่าตาชั่ง** เพื่อเปิดหน้า `/scale-test` |
| ตัวเลขสดขึ้น แต่ **ผิดหน่วย** (เช่นได้ 12,480,000 แทน 12,480) | ค่า **Conversion Factor** บนตาชั่งตั้งไม่ถูก (ตาชั่งส่งกรัมแต่ตั้งไว้เป็น 1) | แจ้งแอดมิน — กรัม→กก. ต้องเป็น `0.001`, ตัน→กก. เป็น `1000` **อย่าพิมพ์แก้เอง เพราะจะบันทึกว่าเป็น Manual** |
| กด **บันทึกน้ำหนัก** แล้วขึ้นข้อความยาวเป็นภาษาโปรแกรม (traceback) | เซิร์ฟเวอร์ปฏิเสธ แต่หน้าจอแสดงข้อความดิบ | อ่านบรรทัดที่มีคำว่า `ValidationError` — มักเป็น *ต้องกรอกเหตุผลชั่งซ้ำ*, *tare ต้องน้อยกว่า gross*, หรือ *ใบส่งของไม่มีใบสั่งซื้อผูกอยู่* |
| กดบันทึกแล้ว **ไม่มีอะไรเกิดขึ้นเลย** ไม่มีข้อความ ไม่มีสลิป | เซิร์ฟเวอร์ปฏิเสธแบบเงียบ (เกิดขึ้นได้ในบางการตั้งค่าเซิร์ฟเวอร์) | ลองใหม่ 1 ครั้ง ถ้ายังเงียบ **ให้แจ้งแอดมิน** และอย่าเดาว่าบันทึกสำเร็จ — เช็คโดยรีเฟรชหน้าแล้วเลือกใบส่งของใหม่ ดูว่ามี ✔ ที่แท็บหรือไม่ |
| บันทึก Tare ไม่ผ่าน ขึ้นว่า tare ต้องน้อยกว่า gross | ใส่ค่า Tare มากกว่าหรือเท่ากับ Gross (เช่นสลับแท็บผิด) | ตรวจว่าอยู่แท็บถูกต้อง แล้วใส่ค่าใหม่ |
| แก้ทะเบียนรถบนใบส่งของไม่ได้ | มีน้ำหนักบันทึกไว้แล้ว ระบบล็อกทะเบียนไว้กันสลับรถ | ต้อง **ยกเลิกใบส่งของ** แล้วให้ออฟฟิศออกใบใหม่ |
| แผงตรวจสอบน้ำหนักไม่โผล่ | ยังขาด Net (ต้องมีทั้ง Gross และ Tare) หรือฝั่งชั่งถุงยังไม่ได้ชั่งอะไรเลย | ทำให้ครบทั้งสองฝั่งก่อน |
| ค่าต่างเป็น **สีแดง** | น้ำหนักตาชั่งรถกับผลรวมถุงห่างกันเกินเกณฑ์ 2 เท่า | ชั่งซ้ำฝั่งที่สงสัย ตรวจว่าลงของหมดจริงไหม มีของตกค้างในกระบะหรือไม่ ถ้ายังไม่หาย → ปล่อยให้เป็น `Needs Review` แล้วให้หัวหน้าตัดสิน |
| ปุ่ม **เสร็จสิ้นใบส่งของ** กดไม่ได้ (เป็นสีเทา) | มีรายการที่ขาดในกรอบเตือนสีเหลือง | ทำให้ครบตามที่แจ้ง — ถ้าข้อความขึ้นเป็น `missingGrossWeight`/`missingTareWeight`/`noScrapWeights` แปลว่า ขาดน้ำหนักขาเข้า / ขาออก / น้ำหนักเศษวัสดุ ตามลำดับ |
| กด **เสร็จสิ้น** แล้วขึ้นว่า "Cannot complete: dropoff is paused" | ฝั่งชั่งถุงกดพักงานไว้ | ให้ฝั่งชั่งถุงกด **ทำงานต่อ (Resume)** ก่อน |
| ปุ่ม 📷 กดไม่ได้ | ยังไม่ได้บันทึกน้ำหนักของแท็บนั้น | บันทึกน้ำหนักก่อน แล้วปุ่มจะใช้งานได้ |
| สลิปไม่พิมพ์ออกมา | เบราว์เซอร์บล็อกป๊อปอัป/การพิมพ์ หรือเครื่องพิมพ์ไม่พร้อม | กด **🖶 Print** บนหัวจอเพื่อพิมพ์ซ้ำ อนุญาตป๊อปอัปของเว็บนี้ในเบราว์เซอร์ |
| กด **🖶 Print** แล้วขึ้น `noRecentWeight` หรือข้อความเรื่อง "finish weighing" | ยังไม่ได้เลือกใบส่งของ หรือใบส่งของนี้ยังไม่มีใบชั่งรถ | เลือกใบส่งของที่มีการชั่งแล้วก่อน (ข้อความนี้เขียนไว้สำหรับหน้าชั่งถุง — ในหน้านี้ให้อ่านว่า *ยังไม่มีใบชั่งให้พิมพ์*) |
| ค้นใบส่งของด้วยเลขที่ถูกต้องแล้วไม่เจอ | ค้นหาแบบบางส่วนจำกัดที่ **±3 วัน** จากวันนี้ | พิมพ์ **เลขที่เต็ม** `DO-260821-00003` หรือ **เลขทะเบียนเต็ม** — ทั้งสองแบบค้นได้ไม่จำกัดวันที่ |
| เลือกด้วย `Enter` แล้ววันที่ขึ้นเป็น `-` | ข้อบกพร่องที่ทราบแล้ว | ใช้เมาส์คลิกเลือกแทน |
| แก้ไขน้ำหนักจากหน้า Desk แล้วค่าต่างไม่อัปเดต | ข้อบกพร่องที่ทราบแล้ว — การแก้จากหน้า Desk ไม่คำนวณค่าต่างใหม่ | **แก้น้ำหนักจากหน้าจอนี้เสมอ** (ใช้ขั้นตอนชั่งซ้ำ) อย่าแก้จากหน้า Desk |
| หน้าจอไม่อัปเดตหลังแอดมินแก้ระบบ | เบราว์เซอร์เก็บไฟล์เก่าไว้ได้ถึง 12 ชั่วโมง (หน้านี้ไม่มีตัวล้างแคช) | กด **Ctrl + Shift + R** เพื่อโหลดใหม่แบบล้างแคช |
| ข้อความบางจุดขึ้นเป็นรหัสอังกฤษทั้งที่เลือกภาษาไทย | คีย์แปลภาษาขาด 8 ตัว (ข้อบกพร่องที่ทราบแล้ว) | ไม่กระทบข้อมูล — อ่านความหมายจากตารางในข้อ 5 และ 6 |

## 9. Quick reference / สรุป

### ปุ่ม / Buttons

| ปุ่ม / Button | ทำอะไร / Does |
|---|---|
| **←** (มุมซ้ายบน) | กลับหน้า `/pos` (ไม่ปิดกะ) |
| **⚖ ชื่อตาชั่ง ●** | เปิดเมนู: เชื่อมต่อใหม่ / ตัดการเชื่อมต่อ / ตั้งค่าตาชั่ง (เปิด `/scale-test`) |
| **🌐 EN / TH** | สลับภาษา |
| **☀ / 🌙** | สลับธีมสว่าง–มืด |
| **🖶 Print** | พิมพ์สลิปใบชั่งรถล่าสุดซ้ำ |
| **ปิดกะ / Close Session** | ปิดกะและปลดล็อกตาชั่ง (ถามยืนยันก่อน) |
| **แท็บ Gross / Tare** | สลับด้านที่จะชั่ง — ✔ เขียว = บันทึกแล้ว |
| **📷 สแกน** | สแกน QR/บาร์โค้ดของใบส่งของ |
| **📷 รูปถ่าย** | ถ่ายรูปแนบใบชั่งของแท็บนั้น (ต้องบันทึกน้ำหนักก่อน) |
| **บันทึกน้ำหนัก / Save Weight** | เปิดหน้าต่างยืนยัน → บันทึก → พิมพ์สลิปอัตโนมัติ |
| **💬 หมายเหตุ** | หมายเหตุระดับใบส่งของ (✔ = มีข้อความแล้ว) |
| **✔ เสร็จสิ้นใบส่งของ** | ปิดงานใบส่งของ (โผล่เมื่อมีครบ Gross + Tare) |
| **✕** บนการ์ดใบส่งของ | ล้างการเลือก กลับไปช่องค้นหา |

### แป้นพิมพ์ / Keyboard

| ปุ่ม | ทำอะไร |
|---|---|
| `↓` `↑` | เลื่อนในรายการผลค้นหา |
| `Enter` | เลือกรายการที่ไฮไลต์ |
| `Esc` | ปิดรายการผลค้นหา |

### ตัวเลขทั้งหมด / The numbers

| ชื่อ | ความหมาย | คำนวณจาก |
|---|---|---|
| น้ำหนักรวม / Gross | รถ + ของ | ชั่งครั้งที่ 1 |
| น้ำหนักเปล่า / Tare | รถเปล่า | ชั่งครั้งที่ 2 |
| **น้ำหนักสุทธิ / Net** | **ของที่รับเข้าตามตาชั่งรถ** | **Gross − Tare** |
| น้ำหนักเศษวัสดุรวม / Total Scrap | ผลรวมถุงที่ชั่งทีละใบ | มาจากหน้าชั่งถุง |
| ค่าต่างรถ / Truck Variance | Net − Total Scrap | เกณฑ์เริ่มต้น 0.1% |
| ค่าต่างแจ้ง / Indicated Variance | น้ำหนักที่ผู้ขายแจ้ง − น้ำหนักจริง | เกณฑ์เริ่มต้น 0.1% |

### สถานะใบส่งของ / Drop-off statuses

| สถานะ | หมายความว่า | ทำอะไรต่อได้ |
|---|---|---|
| `Draft` | ยังไม่ครบข้อมูล | ออฟฟิศต้องกรอกทะเบียนรถและเวลานัดหมาย |
| `Scheduled` | พร้อมแล้ว รอรถมา | ชั่งได้เลย — ชั่งครั้งแรกจะเปลี่ยนเป็น In Progress เอง |
| `In Progress` | กำลังชั่งอยู่ | ชั่งต่อ / ชั่งซ้ำ / กดเสร็จสิ้นได้ |
| `Paused` | ฝั่งชั่งถุงพักงานไว้ | **กดเสร็จสิ้นไม่ได้** ต้องให้ฝั่งนั้นกด Resume ก่อน |
| `Completed` | ปิดงานแล้ว | ดูอย่างเดียว — ถ้าต้องแก้ ให้หัวหน้าเปิดใหม่จากหน้า Desk |
| `Cancelled` | ยกเลิก | ไม่ทำอะไรต่อ |

### สถานะตรวจสอบ / Verification statuses

| สถานะ | หมายความว่า | ต้องทำอะไร |
|---|---|---|
| `Pending` | ยังชั่งไม่ครบทั้งสามตัวเลข (Gross, Tare, น้ำหนักเศษ) | ชั่งให้ครบทุกฝั่ง |
| `Verified` | ค่าต่างทุกตัวอยู่ในเกณฑ์ | ไม่ต้องทำอะไร |
| `Needs Review` | ชั่งครบแล้วแต่มีค่าต่างเกินเกณฑ์ | หัวหน้าตรวจและอนุมัติจากหน้า Desk |

### บนสลิปใบชั่งรถ / On the printed slip

| สิ่งที่เห็น | หมายความว่า |
|---|---|
| ตัวเลขตัวใหญ่กลางสลิป | น้ำหนักที่ชั่งได้ (กก.) |
| `[X] ขาเข้า Gross` | ใบนี้คือชั่งเข้า |
| `[X] ขาออก Tare` | ใบนี้คือชั่งออก |
| `[A] Scale` | ตัวเลขมาจากตาชั่งอัตโนมัติ |
| `[M] Manual` | ตัวเลขพิมพ์มือ |
| `รูปภาพ: 3 รูป` | มีรูปแนบ 3 รูป |
| `** ชั่งซ้ำ **` | ใบนี้ผ่านการชั่งซ้ำ พร้อมเหตุผลที่กรอกไว้ |
| QR อันบน | ใบส่งของ (`DO-…`) |
| QR อันล่าง | ใบชั่งรถใบนี้ (`TW-…`) |
