# POS Scrap Terminal — Operator Guide / คู่มือผู้ใช้งาน

> **Status:** Production
> **Who / ใคร:** POS Operator, POS Manager, System Manager
> **Where / ที่ไหน:** `/pos` → เลือกการ์ด **Scrap Weighing** → `/pos/terminal?session=SES-…`
> **Last verified:** 2026-08-21 against `feature/container-redesign`

---

## 1. What this is for / งานนี้คืออะไร

หน้าจอนี้คือ **โต๊ะชั่งของ** ครับ ของที่ลงจากรถแล้วถูกแยกใส่ถุง ใส่ถัง หรือวางบนพาเลท จะถูกชั่งทีละใบที่หน้าจอนี้ ทุกครั้งที่กดบันทึก ระบบจะสร้าง "ภาชนะ" (Container) หนึ่งรายการ พร้อมพิมพ์สติ๊กเกอร์ติดที่ถุงใบนั้นทันที

This screen is the **bench scale station**. After material comes off the truck and is separated into bags, bins, or pallets, each one is weighed here — one at a time. Every save creates one **Scrap Weight Container** record and immediately prints a sticker for that physical bag.

หน้าจอนี้ **ไม่ได้** ชั่งรถ การชั่งรถอยู่ที่ [11 — Truck Terminal](11-truck-terminal.md)
This screen does **not** weigh trucks. That is [11 — Truck Terminal](11-truck-terminal.md).

**เมื่อไหร่ที่ใช้ / When you use it:** เมื่อรถชั่งขาเข้าเสร็จแล้ว และเริ่มลงของแยกเกรด
Once the truck has been weighed in and material is being separated by grade.

**ผลลัพธ์ / What you end up with:**
- ภาชนะหลายรายการ (`CTN-2608-00001`, `CTN-2608-00002`, …) ผูกกับใบส่งของหนึ่งใบ / many Containers tied to one Drop-off
- สติ๊กเกอร์หนึ่งใบต่อหนึ่งถุง / one sticker per bag
- เมื่อกด **เสร็จสิ้น** จะได้ใบชั่งรวม `WGT-260821-00001` สำหรับส่งให้ผู้ขาย / on **Complete**, one combined Scrap Weight receipt for the supplier

## 2. Before you start / เตรียมก่อนเริ่ม

| ต้องมี / You need | หมายเหตุ / Notes |
|---|---|
| สิทธิ์ **POS Operator** / the **POS Operator** role | ถ้าไม่มี หน้า `/pos` จะขึ้น "Access Denied" / without it `/pos` shows *Access Denied* |
| เบราว์เซอร์ **Chrome** หรือ **Edge** / **Chrome** or **Edge** | Firefox และ Safari ต่อเครื่องชั่งไม่ได้ (ไม่รองรับ WebSerial) — ยังกรอกน้ำหนักเองได้ / Firefox and Safari cannot talk to the scale (no WebSerial); manual entry still works |
| **กะที่เปิดอยู่ (Session)** / an open **session** | เปิดจากหน้า `/pos` เท่านั้น เข้า `/pos/terminal` ตรง ๆ ไม่ได้ / opened from `/pos`; going straight to `/pos/terminal` bounces you back |
| **เครื่องชั่งประเภท Scrap** ที่ว่างอยู่ / a free **Scrap**-type scale | 1 เครื่องชั่ง = 1 กะ ถ้ามีคนใช้อยู่จะเลือกไม่ได้ / one scale, one session — an in-use scale cannot be picked |
| **ใบส่งของ (Drop-off)** ที่มีอยู่แล้ว / an existing **Drop-off** | หน้าจอนี้สร้างใบส่งของไม่ได้ ต้องมีมาก่อน / this screen cannot create one |
| เครื่องพิมพ์สติ๊กเกอร์ / a sticker printer | ถ้าไม่มี ก็ยังบันทึกได้ แต่จะไม่มีสติ๊กเกอร์ติดถุง / saving still works, you just get no label |

> ⚠️ **เครื่องชั่งเลือกได้ครั้งเดียวต่อกะ / A scale can be chosen only once per session.**
> เลือกผิดแล้วเปลี่ยนไม่ได้ ต้องปิดกะแล้วเปิดใหม่
> If you pick the wrong one you must close the session and open a new one.

## 4. Walkthrough: ชั่งของทั้งคันรถ / Weighing a whole load

**สถานการณ์ / Scenario:** โรงหล่อ ก. ส่ง `ทองแดงปอก` กับ `ทองแดงเล็ก` มา ใบส่งของคือ `DO-260821-00003` รถชั่งขาเข้าไปแล้ว ตอนนี้ลงของแยกใส่ถุง

### 4.1 เปิดกะและเลือกเครื่องชั่ง / Open a session and pick a scale

1. **เปิด `/pos`** — Open `/pos`
   → เห็นการ์ด 3 ใบ: Scrap Weighing, Truck Scale, Production Sorting
2. **ถ้ามีหลายโปรไฟล์ เลือกโปรไฟล์ก่อน** — pick your profile if the dropdown is showing
   → โปรไฟล์เป็นตัวกำหนดว่าเกรดอะไรจะขึ้นในช่องซ้าย / the profile decides which grades appear on the left
3. **กดการ์ด `Scrap Weighing`** — click the **Scrap Weighing** card
   → ระบบเปิดกะใหม่ แล้วพาไป `/pos/terminal?session=SES-260821-00010`
4. **หน้าต่าง "เลือกเครื่องชั่ง" เด้งขึ้นมาทันที และปิดไม่ได้** — the **เลือกเครื่องชั่ง / Select Scale** dialog opens and has no close button
   → ต้องเลือกเครื่องชั่งก่อนถึงจะใช้หน้าจอได้ / you cannot use the terminal until a scale is bound
5. **เลือกจากรายการ** เช่น `SCALE-001 - Main Yard` — pick from the dropdown, e.g. `SCALE-001 - Main Yard`
   → ถ้าเครื่องไหนขึ้น `(กำลังใช้งาน)` แปลว่ามีกะอื่นถืออยู่ กดไม่ได้ / `(กำลังใช้งาน)` / *In Use* means another session holds it — it is greyed out
   → ถ้าขึ้น `(ไม่พร้อมใช้งาน)` แปลว่าถูกปิดใช้งานไว้ / `(ไม่พร้อมใช้งาน)` / *Not Active* means it is disabled
   → กล่องข้อมูลเครื่องชั่งโผล่ขึ้นมา: ชื่อ, ประเภท, ที่ตั้ง / the info box appears with name, type, location
6. **กด `ยืนยันเครื่องชั่ง` / Confirm & Connect Scale**
   → เบราว์เซอร์เด้งหน้าต่างขอเลือกพอร์ต USB/Serial ให้เลือกพอร์ตของเครื่องชั่งแล้วกด Connect / Chrome asks you to pick the serial port — choose the scale's port
   → หน้าจอขึ้น "กำลังเชื่อมต่อเครื่องชั่ง..." พร้อมค่าที่บันทึกไว้ เช่น `2400 baud, 7E1`
7. **รอจนขึ้น "เชื่อมต่อเครื่องชั่งสำเร็จ!"** — wait for **เชื่อมต่อเครื่องชั่งสำเร็จ! / Scale connected successfully!**
   → เห็น `โปรโตคอล: STX-M` และ `น้ำหนักปัจจุบัน: 0.00 kg`
8. **กด `ดำเนินการต่อ` / Continue**
   → หน้าต่างปิด ป้ายเครื่องชั่งบนแถบบนขึ้นชื่อ `SCALE-001` พร้อมจุดสีเขียว

> ต่อเครื่องชั่งไม่ติด? ข้ามไป [5.1](#51-walkthrough-กรอกน้ำหนักเอง--manual-weight-entry)
> Scale won't connect? See [5.1](#51-walkthrough-กรอกน้ำหนักเอง--manual-weight-entry).

### 4.2 เรียกใบส่งของ / Load the drop-off

9. **พิมพ์ `DO-260821-00003` ในช่อง `รหัสรอบรับ`** — type `DO-260821-00003` into the **Drop-off ID** box
   → รอ 0.3 วินาที รายการที่ตรงจะโผล่ใต้ช่อง กดเลือก หรือกด ↓ แล้ว Enter / after a 0.3s pause matches drop down; click one, or use ↓ then Enter
   → **หรือ** กดปุ่ม `สแกน` แล้วส่อง QR บนใบคิว / **or** press **สแกน / Scan** and point the camera at the QR on the queue slip
10. **การ์ดใบส่งของแสดงขึ้น** — the drop-off card appears
    → ผู้ขาย `โรงหล่อ ก.` · ทะเบียน `70-1234` · สถานะ `Scheduled` · น้ำหนักรถ (ขาเข้า) `12,480.00 Kg`
    → ช่องขวาว่าง ขึ้นข้อความ "ยังไม่มีภาชนะ — เลือกเกรดจากรายการสินค้าเพื่อเริ่มชั่ง"
    → แถบปุ่มล่างขึ้นปุ่ม `เสร็จสิ้น`

### 4.3 ชั่งถุงใบแรก / Weigh the first bag

11. **วางถุงบนเครื่องชั่ง** — put the bag on the scale
    → ตัวเลขในการ์ดชั่งวิ่งตามเครื่องชั่ง พอนิ่งจะขึ้นป้าย `คงที่ / stable`
12. **กดปุ่มเกรด `ทองแดงปอก` ในช่องซ้าย** — tap the grade button `ทองแดงปอก` on the left
    → ปุ่มนั้นสว่างขึ้น
    → ช่อง `เกรด` เปลี่ยนจาก "เลือกเกรดจากรายการสินค้า" เป็นป้ายชื่อ `ทองแดงปอก ✕`
    → ปุ่ม `บันทึก & พิมพ์สติ๊กเกอร์` และ `ถ่ายรูป` เปิดใช้งาน
13. **ตรวจตัวเลขในช่อง `น้ำหนักสุทธิ`** — check the **น้ำหนักสุทธิ / Net Weight** box
    → ระบบเติมให้อัตโนมัติจากเครื่องชั่ง เช่น `246.70`
14. **⚠️ คลิกในช่องน้ำหนักแล้วพิมพ์ตัวเลขนั้นซ้ำ** — **click into the weight box and retype the number**
    → จำเป็นครับ เพราะถ้าปล่อยให้เป็นค่าที่มาจากเครื่องชั่งตรง ๆ การบันทึกจะขึ้น error สีแดง `Entry Method cannot be "Scale"` ดูรายละเอียดที่ [ตาราง §6](#6-what-can-go-wrong--ปัญหาที่พบบ่อย)
    → Required today: saving a value that came straight off the live scale fails with a red `Entry Method cannot be "Scale"` error. Retyping it flips the field to manual mode and the save succeeds. See [§6](#6-what-can-go-wrong--ปัญหาที่พบบ่อย).
15. **เลือก `ประเภทภาชนะ`** — pick the **Container Type**: `ถุง / Bag` (ค่าเริ่มต้น), `ถัง / Bin`, `พาเลท / Pallet`, `อื่น ๆ / Other`
16. **(ถ้าต้องการ) พิมพ์ `หมายเหตุ`** — optionally type a remark, e.g. `ถุงเปียก`
17. **กด `บันทึก & พิมพ์สติ๊กเกอร์`** — press **บันทึก & พิมพ์สติ๊กเกอร์ / Save & Print Sticker**
    → ขึ้นข้อความเขียว "เพิ่มภาชนะแล้ว / Container added"
    → สติ๊กเกอร์พิมพ์ออกทันที (พิมพ์ผ่าน iframe ที่ซ่อนอยู่ ไม่มีหน้าต่างเด้ง)
    → แถวใหม่โผล่ในช่องขวา: `ทองแดงปอก · CTN-2608-00001 · ถุง · 246.70 Kg · [ใช้งาน]`
    → ตัวเลขบนหัวช่องขวาเปลี่ยนเป็น **1** และ `246.70 Kg`
    → การ์ดชั่งล้างตัวเอง: เกรดหาย, ช่องน้ำหนักว่าง, หมายเหตุว่าง, ประเภทกลับเป็น `ถุง`
    → สถานะใบส่งของเปลี่ยนจาก `Scheduled` เป็น `In Progress` โดยอัตโนมัติ ปุ่ม `หยุดชั่วคราว` โผล่ขึ้นมา
18. **ติดสติ๊กเกอร์ที่ถุง แล้วยกลง** — stick the label on the bag and take it off the scale

### 4.4 ชั่งถุงที่เหลือ / Weigh the rest

19. **ทำซ้ำข้อ 11–18 ทุกถุง** — repeat steps 11–18 for every bag
    → เปลี่ยนเกรดได้ทุกใบ กดปุ่มเกรดใหม่ในช่องซ้ายก่อนบันทึก / change grade any time by tapping a different button before saving
    → ตัวเลขบนหัวช่องขวาเพิ่มขึ้นเรื่อย ๆ: `2 · 349.10 Kg`, `3 · 412.90 Kg` …

### 4.5 ปิดงาน / Finish

20. **กด `เสร็จสิ้น` / Complete ในแถบปุ่มล่าง** — press **เสร็จสิ้น / Complete**
    → เบราว์เซอร์ถามยืนยัน `เสร็จสิ้น?` กด OK
21. **ระบบทำ 2 อย่างต่อกัน** — two things happen back to back:
    → **หนึ่ง** รวมทุกถุงเป็นใบชั่งเดียว `WGT-260821-00001` แล้วสั่งพิมพ์ใบคิวสองภาษาให้ทันที ขึ้นข้อความ "ออกใบชั่ง / Receipt issued"
    → **สอง** ปิดใบส่งของ ขึ้นข้อความ "เสร็จสิ้น / Completed"
22. **หน้าจอล้างตัวเอง** — the workspace clears
    → การ์ดใบส่งของหาย ช่องขวาว่าง ช่องค้นหาพร้อมรับใบถัดไป
23. **ส่งใบชั่งที่พิมพ์ออกมาให้ผู้ขาย** — hand the printed receipt to the supplier

**เสร็จแล้วได้อะไร / Result:** ใบส่งของสถานะ `Completed`, ภาชนะทุกใบผูกกับใบนี้, ใบชั่ง `WGT-…` หนึ่งใบที่ยื่นแล้ว
The Drop-off is `Completed`, every container is attached to it, and one submitted `WGT-…` receipt exists.

**ตรวจยังไง / How to confirm:** ค้นใบส่งของนั้นซ้ำในช่องค้นหา — การ์ดจะขึ้นสถานะ `Completed` และช่องกลางจะแทนที่ด้วยแบนเนอร์ "ใบดร็อปออฟเสร็จสิ้นแล้ว กดเปิดใหม่ด้านบนเพื่อเพิ่มถุง"

## 5. Walkthroughs: กรณีอื่น ๆ / Other cases

### 5.1 Walkthrough: กรอกน้ำหนักเอง / Manual weight entry

ใช้เมื่อ: เครื่องชั่งต่อไม่ติด, ไม่มีสาย, ใช้เบราว์เซอร์ที่ไม่รองรับ, หรือชั่งจากเครื่องอื่นแล้วมากรอก
Use when: the scale won't connect, there is no cable, the browser is unsupported, or the weight was read on another device.

**ทางที่ 1 — เลือกตั้งแต่แรก / Choose it up front**

1. ในหน้าต่าง `เลือกเครื่องชั่ง` เลือกเครื่องชั่งจากรายการตามปกติ
2. กดปุ่มล่าง **`ยืนยันเครื่องชั่ง (กรอกเอง)` / Confirm Scale (Manual Entry)** แทนปุ่มเขียว
   → ขึ้นข้อความ "ตั้งค่าเครื่องชั่งแล้ว - ใช้การกรอกน้ำหนักเอง"
   → ป้ายเครื่องชั่งขึ้นจุดสีแดง (ไม่ได้เชื่อมต่อ) แต่ใช้งานหน้าจอได้ปกติ

**ทางที่ 2 — ต่อไม่ติดแล้วเปลี่ยนใจ / After a failed connection**

1. กด `ยืนยันเครื่องชั่ง` แล้วเชื่อมต่อไม่สำเร็จ
   → หน้าต่างขึ้น ✗ "ไม่สามารถเชื่อมต่อเครื่องชั่งได้" พร้อมข้อความ error
2. มี 3 ปุ่มให้เลือก / three buttons appear:
   - `ลองใหม่ / Try Again` — ปิดหน้าต่างแล้วลองอีกครั้ง
   - `ตั้งค่าเครื่องชั่งใหม่ / Reconfigure Scale` — เปิดหน้า `/scale-test` ในแท็บใหม่ (ดู [§5.8](#58-walkthrough-ตั้งค่าเครื่องชั่งใหม่--reconfigure-a-scale))
   - `ใช้การกรอกเอง / Use Manual Entry` — ผูกเครื่องชั่งกับกะแล้วไปต่อเลย
3. กด `ใช้การกรอกเอง`

**แล้วชั่งยังไง / Then how you weigh**

4. ในการ์ดชั่ง ตรงที่ปกติแสดงตัวเลขวิ่ง จะขึ้นคำว่า **`ป้อนเอง / Manual`** แทน
5. กดเกรดในช่องซ้าย
6. **พิมพ์น้ำหนักลงช่อง `น้ำหนักสุทธิ` เอง** เช่น `246.7`
7. เลือกประเภทภาชนะ แล้วกด `บันทึก & พิมพ์สติ๊กเกอร์` ตามปกติ

> ข้อดีของทางนี้: ไม่เจอปัญหา error `Entry Method cannot be "Scale"` เลย เพราะไม่มีค่ามาจากเครื่องชั่ง
> Upside: the `Entry Method cannot be "Scale"` failure cannot happen on this path, because no value ever comes from the live stream.

---

### 5.2 Walkthrough: ชั่งถุงใหม่ / Reweigh a bag

ใช้เมื่อ: ตัวเลขผิด, ชั่งตอนที่ยังไม่นิ่ง, หรือมีของตกออกจากถุง
Use when: the number was wrong, the reading wasn't settled, or material fell out.

1. **หาแถวของถุงนั้นในช่องขวา** — find the row in the journal
   → เช่น `ทองแดงปอก · CTN-2608-00001 · 246.70 Kg`
   → **หรือ** สแกนสติ๊กเกอร์บนถุง แล้วเลือก `ชั่งใหม่` จากเมนูที่เด้งขึ้น (ดู [§5.6](#56-walkthrough-สแกนสติ๊กเกอร์หาถุง--find-a-bag-by-scanning-its-sticker))
2. **กดปุ่ม `ชั่งใหม่` / Reweigh ในแถวนั้น**
   → หน้าต่างเปิดขึ้น แสดง `CTN-2608-00001` และน้ำหนักเดิม `246.70 Kg`
3. **วางถุงบนเครื่องชั่งอีกครั้ง อ่านค่า แล้วพิมพ์ลงช่อง `น้ำหนักสุทธิ`** เช่น `244.20`
   → หน้าต่างนี้ **ไม่** ดึงค่าจากเครื่องชั่งอัตโนมัติ ต้องพิมพ์เอง / this dialog does **not** auto-fill from the scale — type it
4. **พิมพ์ `เหตุผลในการชั่งใหม่`** เช่น `ชั่งตอนเครื่องยังไม่นิ่ง` — **required**, ว่างไม่ได้
   → ถ้าไม่กรอกจะขึ้น "ต้องระบุเหตุผล / Reason required"
5. **กด `บันทึก` / Save**
   → ขึ้นข้อความ "ชั่งภาชนะใหม่แล้ว / Container reweighed"
   → สติ๊กเกอร์ใบใหม่พิมพ์ออกมา — **ติดทับใบเดิม**
   → ในช่องขวา ถุงเดิมเปลี่ยนสถานะเป็น `ชั่งใหม่แล้ว / Reweighed` และมีแถวใหม่ขึ้นมาแทน
   → น้ำหนักรวมบนหัวช่องขวาปรับตาม

---

### 5.3 Walkthrough: ยกเลิกถุง / Void a bag

ใช้เมื่อ: บันทึกซ้ำ, บันทึกผิดใบส่งของ, หรือถุงนั้นไม่มีอยู่จริง
Use when: it was a duplicate, saved against the wrong drop-off, or the bag doesn't exist.

1. **กดปุ่ม `ยกเลิก` / Void ในแถวของถุงนั้น** (ปุ่มสีแดง)
   → หน้าต่างเปิดขึ้น แสดงชื่อภาชนะ
2. **พิมพ์ `เหตุผลในการยกเลิก`** เช่น `บันทึกซ้ำ` — **required**
3. **กด `ยกเลิก` / Void**
   → ขึ้นข้อความส้ม "ยกเลิกภาชนะแล้ว / Container voided"
   → แถวหายจากรายการหลัก ไปอยู่ในกล่องพับ `ยกเลิก (1)` ที่ท้ายช่องขวา กดเปิดดูได้
   → จำนวนและน้ำหนักรวมบนหัวช่องขวาลดลง

> ถุงที่ยกเลิกแล้ว **ไม่ถูกลบ** ยังอยู่ในระบบเพื่อการตรวจสอบ
> A voided container is **not deleted** — it stays for audit.

---

### 5.4 Walkthrough: หยุดพักแล้วกลับมาทำต่อ / Pause and resume

ใช้เมื่อ: พักเที่ยง, เปลี่ยนกะ, ฝนตก, หรือต้องไปชั่งใบอื่นก่อน
Use when: lunch, shift change, rain, or you must serve another truck first.

**หยุด / Pause**

1. **กด `หยุดชั่วคราว` / Pause ในแถบปุ่มล่าง** (ปุ่มนี้โผล่เฉพาะตอนสถานะ `In Progress`)
2. **พิมพ์เหตุผล (ไม่บังคับ)** เช่น `พักเที่ยง`
3. **กด `หยุดชั่วคราว`**
   → ขึ้นข้อความส้ม "หยุดใบส่งมอบชั่วคราว / Dropoff paused"
   → ปุ่ม `หยุดชั่วคราว` และ `เสร็จสิ้น` หายไป เหลือ `ทำงานต่อ`
   → ล็อกเครื่องชั่งของใบนี้ถูกปล่อย คนอื่นเอาใบนี้ไปชั่งต่อได้

**ทำต่อ / Resume**

4. **เรียกใบส่งของขึ้นมาอีกครั้ง แล้วกด `ทำงานต่อ` / Resume**
   → ขึ้นข้อความเขียว "ทำงานต่อใบส่งมอบ / Dropoff resumed"
   → สถานะกลับเป็น `In Progress` ปุ่มกลับมาครบ รายการถุงเดิมโหลดขึ้นมา
   → ถ้ามีคนอื่นถือใบนี้อยู่ จะขึ้น error บอกว่ากะไหนถืออยู่

---

### 5.5 Walkthrough: เปิดใบที่ปิดไปแล้ว / Reopen a completed drop-off

ใช้เมื่อ: เจอถุงตกหล่นหลังกดเสร็จสิ้นไปแล้ว
Use when: a bag turns up after you already pressed Complete.

1. **พิมพ์รหัสใบส่งของในช่องค้นหา** เช่น `DO-260821-00003`
   → การ์ดขึ้นสถานะ `Completed`
   → **การ์ดชั่งหายไป** แทนที่ด้วยแบนเนอร์ ✔ "ใบดร็อปออฟเสร็จสิ้นแล้ว กดเปิดใหม่ด้านบนเพื่อเพิ่มถุง"
   → แถบปุ่มล่างเหลือปุ่มเดียว: `เปิดใหม่ / Reopen`
2. **กด `เปิดใหม่`**
   → เบราว์เซอร์ถาม `เหตุผลในการเปิดใบนี้ใหม่:` — **ต้องกรอก** ถ้าปล่อยว่างหรือกด Cancel จะไม่ทำอะไร
3. **พิมพ์เหตุผล** เช่น `เจอถุงตกหล่น 1 ใบ` แล้วกด OK
   → ขึ้นข้อความส้ม บอกว่าใบชั่งเดิม `WGT-260821-00001` ถูก **ยกเลิก** แล้ว
   → สถานะกลับเป็น `In Progress` การ์ดชั่งกลับมา
4. **ชั่งถุงที่ตกหล่นตามปกติ** (ข้อ 11–18 ใน §4.3)
5. **กด `เสร็จสิ้น` อีกครั้ง**
   → ได้ใบชั่ง **ใบใหม่** ที่ระบุว่าเป็นฉบับแก้ไข ขึ้นข้อความ "Amended receipt"
   → **ใบเดิมที่ให้ผู้ขายไปแล้วใช้ไม่ได้** ต้องเอาใบใหม่ไปแลก / **the receipt already handed over is void** — swap it for the new one

### 5.6 Walkthrough: สแกนสติ๊กเกอร์หาถุง / Find a bag by scanning its sticker

ใช้เมื่อ: มีถุงอยู่ในมือ แต่ไม่รู้ว่าอยู่ใบส่งของไหน หรือหาแถวในรายการยาว ๆ ไม่เจอ
Use when: you have a bag in hand and need its record, or the journal is too long to scan by eye.

**ทางที่ 1 — พิมพ์/สแกนลงช่องค้นหา / Into the search box**

1. **สแกนหรือพิมพ์ `CTN-2608-00001` ลงช่อง `รหัสรอบรับ`**
   → รอ 0.3 วินาที ระบบรู้เองว่านี่คือรหัสภาชนะ ไม่ใช่ใบส่งของ
   → ช่องค้นหาล้างตัวเอง
   → **ใบส่งของแม่ของถุงนั้นถูกโหลดขึ้นมาทั้งใบ** พร้อมรายการถุงทั้งหมด
   → แถวของถุงใบนั้น **กะพริบเน้นสีอยู่ประมาณ 2.4 วินาที** แล้วเลื่อนมาให้เห็นกลางจอ

**ทางที่ 2 — สแกนด้วยกล้อง / With the camera**

2. **กดปุ่ม `สแกน` ข้างช่องค้นหา** แล้วส่องกล้องไปที่ QR บนสติ๊กเกอร์
   → ได้ยินเสียง beep แล้วเกิดผลเหมือนทางที่ 1
   → กล้องอ่านได้ทั้ง QR ของใบส่งของ (`DO-…`) และของถุง (`CTN-…`) ระบบแยกให้เอง

### 5.7 Walkthrough: ถ่ายรูปถุง / Photograph a bag

ใช้เมื่อ: ของปนเปื้อน, เกรดไม่ตรงที่แจ้ง, หรืออยากเก็บหลักฐาน
Use when: material is contaminated, off-grade, or you simply want evidence.

**ถ่ายก่อนบันทึก / Before saving**

1. **กดเกรดในช่องซ้ายก่อน** — ปุ่ม `ถ่ายรูป` ยังกดไม่ได้จนกว่าจะเลือกเกรด
2. **กด `📷 ถ่ายรูป` / Take Photo**
   → กล้องเปิดขึ้นในหน้าต่าง พร้อมแถบปรับ **ซูม / Zoom** และ **เอียง / Tilt**
3. **กดถ่าย แล้วเลือก `ถ่ายต่อ` หรือ `เสร็จ`** — ถ่ายได้หลายรูปต่อถุง
   → ตัวเลขบนปุ่ม `ถ่ายรูป` เพิ่มขึ้นตามจำนวนรูป เช่น `📷 ถ่ายรูป 2`
4. **บันทึกภาชนะตามปกติ** — รูปจะถูกแนบกับถุงใบนั้นหลังบันทึกสำเร็จ
   → ขึ้นข้อความ "แนบรูปแล้ว / Photos attached"
   → ถ้าแนบไม่สำเร็จบางรูป จะขึ้นข้อความสีส้มบอกจำนวนที่ล้มเหลว — **ตัวถุงบันทึกไปแล้ว รูปเท่านั้นที่หาย**

**ดูรูปที่ถ่ายไว้แล้ว / Viewing saved photos**

5. **ในช่องขวา แถวไหนมีรูปจะมีป้าย `📷2`** — กดที่ป้ายนั้น
   → หน้าต่างเปิดขึ้นแสดงรูปทั้งหมดของถุงใบนั้น
   → ถ้ายังไม่มีรูป จะขึ้น "ยังไม่มีรูปของถุงนี้"

### 5.8 Walkthrough: ตั้งค่าเครื่องชั่งใหม่ / Reconfigure a scale

ใช้เมื่อ: เครื่องชั่งใหม่, เปลี่ยนสาย, ต่อไม่ติดซ้ำ ๆ, หรือน้ำหนักออกมาผิดหน่วย (เช่นได้ 246700 แทน 246.7)
Use when: a new scale, a changed cable, repeated connection failures, or readings in the wrong unit (246700 instead of 246.7).

1. **กดป้ายเครื่องชั่งบนแถบบน แล้วเลือก `ตั้งค่าเครื่องชั่งใหม่` / Reconfigure Scale**
   → เปิดหน้า `/scale-test` ในแท็บใหม่
2. **ในหน้านั้น เลือกเครื่องชั่งที่จะตั้งค่าจากรายการบนสุด**
3. **กด `🔍 Auto-Detect Scale`**
   → เลือกพอร์ตอีกครั้ง แล้วระบบไล่ทดสอบการตั้งค่า 7 แบบเรียงตามความน่าจะเป็น (4800/8N1 → 2400/7E1 → 1200/7E1 → …) แบบละ 5 วินาที
   → บันทึกการทดสอบวิ่งอยู่ในกล่อง `Connection Log` ด้านล่าง
   → พอเจอจะขึ้น ✓ พร้อมค่า baud/data bits/parity/stop bits และชื่อโปรโตคอล
4. **ขั้นที่ 2 — ดูตัวเลขดิบ** — หน้าจอแสดง *ค่าดิบ* จากเครื่องชั่ง ยังไม่แปลงหน่วย
5. **ขั้นที่ 3 — เทียบหน่วย: วางของหนัก 1 กิโลกรัมพอดีบนเครื่องชั่ง**
   → กด `📖 Use Current Reading` หรือพิมพ์ตัวเลขที่เห็นลงไปเอง
   → ระบบคำนวณ **ตัวคูณ** ให้ เช่น อ่านได้ `1000` → ตัวคูณ `0.001000` (เครื่องส่งเป็นกรัม)
   → บรรทัด Verification ต้องขึ้น `= 1.000 kg ✓`
6. **ขั้นที่ 4 — กด `💾 Save to Database`**
   → ค่าทั้งหมดถูกเก็บกับเครื่องชั่งตัวนั้น ครั้งต่อไปที่เปิดกะ ระบบจะลองค่านี้ก่อนเป็นอันดับแรก (เร็วกว่ามาก)
7. **กลับไปที่แท็บ POS แล้วกด `Disconnect & Refresh` ในเมนูป้ายเครื่องชั่ง**

> ต้องปิดกะที่ใช้เครื่องชั่งตัวนั้นก่อน ไม่งั้นพอร์ต USB จะถูกจับไว้และหน้า `/scale-test` เปิดไม่ได้
> Close any session holding that scale first, or the USB port stays locked and `/scale-test` cannot open it.

---

### 5.9 Walkthrough: เครื่องชั่งหลุดกลางคัน / The scale drops out mid-shift

1. **สาย USB หลุด หรือเครื่องชั่งดับ**
   → ขึ้นข้อความส้ม "เครื่องชั่งหลุด กรุณาเชื่อมต่อใหม่หรือเสียบ USB อีกครั้ง"
   → จุดบนป้ายเครื่องชั่งเปลี่ยนเป็นสีแดง
   → การ์ดชั่งเปลี่ยนไปแสดงคำว่า `ป้อนเอง`
2. **เสียบสายกลับ แล้วกดป้ายเครื่องชั่ง → `เชื่อมต่อใหม่` / Reconnect**
   → ขึ้นข้อความ "กรุณาเลือกพอร์ต" เลือกพอร์ตอีกครั้ง
   → สำเร็จ: จุดกลับเป็นสีเขียว ขึ้น "Scale reconnected"
3. **ยังไม่ติด?** กด `Disconnect & Refresh` — ตัดการเชื่อมต่อแล้วรีโหลดหน้า
4. **ระหว่างนี้ทำงานต่อได้เลย** — พิมพ์น้ำหนักลงช่องเอง ไม่ต้องรอ

---

### 5.10 Walkthrough: ปิดกะ / Closing your session

1. **(ถ้าอยากดูยอด) กด `สรุป` / Summary บนแถบบน**
   → แสดง `จำนวนครั้งที่ชั่ง` และ `น้ำหนักรวม` ของกะนี้
2. **กด `ปิดเซสชัน` / Close Session** (ปุ่มแดงขวาสุด)
   → หน้าต่างยืนยันขึ้นมาพร้อมสรุปยอด
3. **กดยืนยัน**
   → ระบบตัดการเชื่อมต่อเครื่องชั่งก่อน แล้วจึงปิดกะ
   → ขึ้นข้อความ "ปิดเซสชันสำเร็จ / Session closed successfully"
   → กลับไปหน้า `/pos` ภายใน 1 วินาที
   → **ล็อกเครื่องชั่งถูกปล่อย** คนกะถัดไปเลือกเครื่องนี้ได้แล้ว

> **ปิดกะทุกครั้งที่เลิกงาน** ถ้าลืม ระบบจะปิดให้เองเมื่อ *ไม่มีการบันทึกถุงใด ๆ* เกิน 90 นาที — อย่าพึ่งพากลไกนี้ เพราะเวลานับจากการบันทึกครั้งล่าสุด ไม่ใช่จากการที่คุณยังเปิดหน้าจอค้างไว้
> **Always close your session.** The system force-closes after 90 minutes with *no container saved* — but that clock is driven by saves, not by the browser being open, so do not rely on it.

## 6. What can go wrong / ปัญหาที่พบบ่อย

| อาการ / Symptom | สาเหตุ / Cause | แก้ยังไง / Fix |
|---|---|---|
| กด `บันทึก & พิมพ์สติ๊กเกอร์` แล้วขึ้นกล่องแดง **`Entry Method cannot be "Scale"`** / red error box on save | **ข้อบกพร่องของระบบ** ค่าที่มาจากเครื่องชั่งโดยตรงถูกส่งเป็นรหัสที่ระบบไม่รู้จัก / **known defect** — a weight taken straight from the live stream is sent with an invalid code | **คลิกในช่อง `น้ำหนักสุทธิ` แล้วพิมพ์ตัวเลขนั้นซ้ำ** แล้วกดบันทึกอีกครั้ง / **click into the Net Weight box and retype the number**, then save again. แจ้งผู้ดูแลระบบด้วย / report it to your admin |
| หน้าต่าง `เลือกเครื่องชั่ง` ปิดไม่ได้ / the Select Scale dialog has no ✕ | ตั้งใจให้เป็นแบบนั้น ต้องมีเครื่องชั่งก่อนถึงชั่งได้ / by design — no scale, no weighing | เลือกเครื่องชั่ง แล้วกดปุ่มใดปุ่มหนึ่งใน 2 ปุ่มล่าง / pick one and press either footer button |
| เครื่องชั่งที่ต้องการขึ้น `(กำลังใช้งาน)` กดไม่ได้ / greyed out as *In Use* | มีกะอื่นถือเครื่องนี้อยู่ / another session holds the lock | ให้คนนั้นกด `ปิดเซสชัน` หรือรอ 90 นาทีให้ระบบปิดเอง / have them close it, or wait for the idle sweep |
| เครื่องชั่งขึ้น `(ไม่พร้อมใช้งาน)` / *Not Active* | ถูกปิดใช้งานในระบบ / `Is Active` is unchecked | แจ้งผู้ดูแลระบบให้เปิดใช้งาน / ask an admin to re-enable it |
| กดการ์ด Scrap Weighing แล้วเด้งไปหน้าชั่งรถ `/pos/truck` | กะนี้ผูกกับเครื่องชั่งประเภท **Truck** ไว้แล้ว / this session is bound to a **Truck** scale | ปิดกะ เปิดใหม่ แล้วเลือกเครื่องชั่งประเภท **Scrap** / close, reopen, pick a **Scrap** scale |
| เข้า `/pos/terminal` ตรง ๆ แล้วเด้งกลับไป `/pos` | URL ไม่มี `?session=…` / no session in the URL | เข้าจากหน้า `/pos` เสมอ / always enter from `/pos` |
| ขึ้น "This session has been closed" | กะถูกปิดไปแล้ว (คุณปิดเอง หรือระบบปิดเพราะไม่มีการใช้งาน 90 นาที) | กลับไป `/pos` แล้วเปิดกะใหม่ |
| ขึ้น "This session belongs to another operator" | ลิงก์ที่เปิดเป็นของคนอื่น | เปิดกะของตัวเองจาก `/pos` |
| ขึ้น "Session not found" | รหัสกะใน URL ผิดหรือถูกลบไปแล้ว | กลับไป `/pos` |
| ปุ่ม `บันทึก` กดไม่ได้ (จาง) | ยังไม่ได้เลือกเกรด **หรือ** ยังไม่ได้เรียกใบส่งของ **หรือ** น้ำหนักว่าง/เป็น 0 | ครบทั้ง 3 อย่างปุ่มถึงจะกดได้ / all three must be set |
| ปุ่ม `📷 ถ่ายรูป` กดไม่ได้ | ยังไม่ได้เลือกเกรด | กดปุ่มเกรดในช่องซ้ายก่อน |
| กดปุ่มเกรดแล้วขึ้น "Select a dropoff first" | ยังไม่ได้เรียกใบส่งของ | ค้นหาหรือสแกนใบส่งของก่อน |
| ต่อเครื่องชั่งแล้วขึ้น "WebSerial API not supported" | ใช้ Firefox หรือ Safari | เปลี่ยนไปใช้ Chrome หรือ Edge หรือกดใช้การกรอกเอง |
| ต่อเครื่องชั่งแล้วขึ้น "ยังไม่ได้ตั้งค่าการเชื่อมต่อเครื่องชั่ง" | เครื่องชั่งตัวนี้ยังไม่เคยตั้งค่า baud/parity | ไปหน้า `/scale-test` ตั้งค่าก่อน (ดู [§5.8](#58-walkthrough-ตั้งค่าเครื่องชั่งใหม่--reconfigure-a-scale)) |
| น้ำหนักออกมาผิดหน่วยมาก เช่น `246700` แทน `246.70` | ตัวคูณหน่วยของเครื่องชั่งยังไม่ได้ตั้ง | ตั้งค่าที่ `/scale-test` ขั้นที่ 3 (ดู [§5.8](#58-walkthrough-ตั้งค่าเครื่องชั่งใหม่--reconfigure-a-scale)) |
| ตัวเลขวิ่งไม่หยุด ไม่ขึ้นคำว่า `คงที่` | ของยังแกว่ง, ลม, หรือถุงพิงอะไรอยู่ | รอให้นิ่ง ถ้ายังไม่นิ่ง ให้พิมพ์ตัวเลขเอง |
| ตัวเลขจากเครื่องชั่ง **ไม่เขียนทับ** ช่องน้ำหนัก | คุณพิมพ์ในช่องนั้นไปแล้ว ระบบจึงหยุดเขียนทับ (ตั้งใจ) | ล้างช่องแล้วบันทึกถุงใบนี้ก่อน หลังบันทึกการ์ดจะรีเซ็ตและรับค่าจากเครื่องชั่งอีกครั้ง |
| กด `บันทึก` แล้วขึ้น "Weight … exceeds scale capacity" | น้ำหนักเกินพิกัดของเครื่องชั่งที่ตั้งไว้ | ชั่งใหม่ให้ถูก หรือแจ้งผู้ดูแลให้แก้พิกัดของเครื่องชั่ง |
| กด `เสร็จสิ้น` แล้วไม่มีอะไรพิมพ์ออกมา | เบราว์เซอร์บล็อกป๊อปอัป หรือไม่มีเครื่องพิมพ์ | ใช้ปุ่ม `🖶 Print` บนแถบบนเพื่อพิมพ์ใบล่าสุดซ้ำ / use the header **Print** button to reprint |
| สติ๊กเกอร์ไม่ออกตอนบันทึก | เครื่องพิมพ์ไม่พร้อม หรือถูกปิดในโปรไฟล์ | กด `พิมพ์สติ๊กเกอร์` ในแถวของถุงนั้นในช่องขวา |
| ช่องขวา (สมุดภาชนะ) ไม่แสดง | จอกว้างน้อยกว่า 1280px | ขยายหน้าต่าง, ลดการซูมของเบราว์เซอร์, หรือหมุนแท็บเล็ตเป็นแนวนอน |
| ขึ้นแบนเนอร์เหลือง "Previous weighing loaded" ทั้งที่เพิ่งเปิดใบ | ใบนี้เคยมีใบชั่งอยู่แล้ว ข้อความนี้เป็นของหน้าจอรุ่นเก่า / leftover from the old flow | **ไม่ต้องสนใจ** ชั่งต่อได้ตามปกติ / harmless — carry on |
| ในช่องซ้าย ไม่มีเกรดที่ต้องการ | เกรดนั้นไม่ได้อยู่ในโปรไฟล์ของคุณ | เช็กแท็บ `ทั้งหมด` ก่อน ถ้ายังไม่มี แจ้งผู้ดูแลให้เพิ่มเข้าโปรไฟล์ |
